
# Statistical Aspects of Clinical Trials in Oncology

Lecture slides and teaching notes for the **Molecular Targets and Cancer
Therapy (MTCT)** half minor.

Designed for undergraduate medical students with basic statistical knowledge,
this lecture introduces the design and analysis of oncology clinical trials.

## Topics covered

- **Phase I:** Dose-finding designs and safety assessment
- **Phase II:** Early evidence of efficacy and sample size planning
- **Phase III:** Randomized trials and time-to-event outcomes

## Repository contents

This repository contains the source code used to generate the lecture slides
and accompanying teaching notes.
